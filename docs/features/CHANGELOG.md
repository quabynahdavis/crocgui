# Changelog — Features

Revision history for documents in `docs/features/`.

## 2026-08-08

### Added
- `OVERVIEW.md` summarising the four feature areas, the cross-cutting behaviours (single concurrent
  transfer, state persistence across navigation, background transfers, universal history recording),
  and the file index.
- `01-send.md` covering the file, folder, text, and clipboard modes, the mixed item list, preview
  popup, code sharing and copying, progress reporting, cancellation, and error states.
- `02-receive.md` covering code phrase format and validation, automatic uppercasing, deep linking
  via the `code` query parameter, output directory precedence, progress, and completion.
- `03-history.md` covering record fields, the send/receive tabs, pinning, deletion with optional
  file removal, clearing, live refresh, and the storage location.
- `04-settings.md` covering appearance, relay, encryption curve, compression, default output
  directory, autostart, and minimize-to-tray, with a consolidated defaults and storage table.
